# IntervalClock 调试安装包

此分支用于分发 Kotlin 原生 Android 应用的调试安装包。

- 安装包：`downloads/IntervalClock-0.1.0-debug.apk`
- 最低 Android 8.0（API 26）。
- 功能：批量等间隔闹钟、多铃声、系统快捷设置磁贴、桌面图标长按快捷入口、番茄钟。
- 已通过构建、Lint、15 项核心单测、4 项 Android 引擎集成测试和 2 项界面测试。
- 锁屏、Doze、声音输出及厂商后台行为仍需真机验收。
- 应用源码目前保存在云工作区，尚未推送到仓库。
